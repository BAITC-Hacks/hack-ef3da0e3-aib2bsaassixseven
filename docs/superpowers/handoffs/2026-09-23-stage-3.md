## Implemented here

Tasks 1, 3, 5, 6, and the backend portion of 7 are committed. The API accepts
and validates an owner-scoped audio upload, persists a queued meeting, resumes
GPU submission/poll/result/ACK after restart, publishes a verified local result
before ACK, retries failed attempts, and performs local TTL cleanup and safe
meeting deletion. Coordinator ticks are serialized across API processes; meeting
mutations use a per-meeting lock.

The internal GPU contract now includes
`GET /internal/v1/jobs/by-key/{meeting_id}/{attempt}`. The GPU service must
reserve the idempotency key before accepting audio, return a durable job or
content-free receipt by key, and retain receipts for seven days. The backend
does not treat a missing job or a lost response as proof of remote deletion.
The exact request/response/error contract is in
`docs/technical/API_CONTRACT.md`.
